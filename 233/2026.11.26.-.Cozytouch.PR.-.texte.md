## What

`cozytouch.set_schedule` and the calendar write `[[minute,setpoint],...]` to every program run. On the 100320 and 100327 runs the device refuses it ("execution ended in state 4", `write_not_completed`). The Cozytouch app writes `[[minute,setpoint,0],...]` there, padded with `[0,0,0]`. This writes the same triplets on those two runs; the 196 and 203 runs are unchanged.

## Evidence (real devices)

- Two Thermor Riva 5 (modelId 1560, productId 53, Wi-Fi, no bridge), release 2026.11.4.
- Before: `set_schedule` refused on both devices, five entries in `writeRefusals`, including `[[420,21],[540,17],[1080,21],[1260,17],...]` with no 00:00 slot, so the missing 00:00 is not the cause.
- After: the same call with triplets is accepted on one device, then on the other. `get_schedule` reads back the same program for all seven days on both.
- Same symptom, same diagnosis (triplets) reported for a Doris 2000W in gduteil/cozytouch#186, untested there.
