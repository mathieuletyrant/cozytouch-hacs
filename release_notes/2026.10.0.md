This release changes how an air-conditioned room behind a Navizone is
controlled, and makes the absence something you can set in one go.

### ⚠️ Navizone rooms: the house's mode moves to its own select

A room's climate entity used to mix two things in one menu : Heat, Cool,
Auto and Dehumidify changed the whole house, Off stopped only that room.
Each room now has a **System service** select, the app's own dropdown :
System off, Heat, Cool, Auto, Dehumidify. System off is the app's general
stop, which Home Assistant could not send before. The room's climate keeps
off and the mode the house is running, like the toggle in the app. An
automation that asks a room for heat will now fail while the house cools :
change the select instead.

### 🔧 Fixes you will notice

A change you make now shows in every room at once, rather than one room
at a time as polls come round. Editing an away date while the absence was
off could leave the house away and the device not ; a date now only goes
out with the switch. The heating status that read off all summer is
disabled by default on new installs.

### 🌡️ Absence and consumption

The absence is set with its dates in one action,
`cozytouch.set_away_mode`, and ended with `cozytouch.clear_away_mode`.
Assist can use both. While it runs, your climate entities show the `away`
preset. Devices that report consumption get today's energy, its cost and
water. That was built from another user's water heater and has not been
seen on a Navizone, which reports none.
